# CLI Projects

This repository contains a collection of command-line interface (CLI) projects written in **C**, **C++**, and **Python**. Each project is a simple demonstration of various programming concepts and problem-solving techniques.

## Projects Overview

### 1. C Projects

| Project Name                  | Description                                              |
|-------------------------------|----------------------------------------------------------|
| **bank_management.c**         | A project for managing banking operations.               |
| **number_guessing_game.c**    | A simple number guessing game.                           |
| **caesar.c**                  | Implementation of the Caesar cipher for encryption.      |
| **credit.c**                  | Basic credit management functionalities.                 |
| **cash.c**                    | Simple cash register management system.                  |

### 2. C++ Projects

| Project Name                  | Description                                              |
|-------------------------------|----------------------------------------------------------|
| **bank_management_system.cpp**| A complete banking management system.                    |
| **tic_tac_toe.cpp**          | A command-line version of the Tic-Tac-Toe game.         |
| **data_structure.cpp**        | Contains various data structure implementations.         |
| **inheritance.cpp**           | Demonstration of inheritance in C++.                     |
| **scrabble.cpp**              | A command-line scrabble game implementation.             |

### 3. Python Projects

| Project Name                  | Description                                              |
|-------------------------------|----------------------------------------------------------|
| **password_manager.py**       | A password manager with encryption and decryption features.|
| **weather_fetcher.py**        | A CLI tool to fetch weather information using an API.    |
| **to_do_list.py**            | A simple to-do list manager with saving and loading capabilities. |
| **file_name_editor.py**      | A tool to edit file names in bulk.                       |
| **readability.py**           | A program to check the readability score of a text.      |
| **KBC_game.py**               | A command-line version of the KBC (Kaun Banega Crorepati) game. |
| **sudoku_game.py**            | A CLI implementation of a Sudoku game.                   |
| **volume.py**                 | A tool to manage media volume on your device.            |
